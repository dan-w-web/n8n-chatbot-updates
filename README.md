# n8n Chatbot Widget — update channel

This repository exists so that WordPress sites running the **n8n Chatbot Widget** plugin can
receive updates **without holding a credential**.

It contains **no source code**. Every release here is a build artifact — a single
`n8n-chatbot.zip`, published automatically by CI in the private source repository.

## Why it exists

The plugin's source repository is private. Plugin Update Checker, which runs inside WordPress and
performs the update check, therefore needed a GitHub personal access token **on every client site**
— in `wp-config.php` or in the database. That meant a live credential with repository read access
sitting in the config of every site running the plugin, expiring on its own schedule, and failing
silently when it did: the site simply stopped seeing updates, with nothing to indicate why.

Pointing the update check at this public repository removes the token entirely. Nothing here is
secret, so nothing needs authenticating.

## What you can do with it

Nothing you would want to. There is no source to read, no issue tracker in use, and no support
offered here. If you are looking at this repository because you run the plugin, the only thing it is
for is the zip attached to each release.

## Verifying a download

Every release carries a `SHA256SUMS` file alongside the zip, generated by the same CI run that built
it.

```
shasum -a 256 -c SHA256SUMS
```
